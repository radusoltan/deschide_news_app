## Instrucțiuni Import Beta Backup:

1. Creează baza de date:
   mysql -h 127.0.0.1 -u USER -p -e "CREATE DATABASE IF NOT EXISTS beta_deschide CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

2. Importă dump-ul (cu progress):
   pv /home/radu/beta_backup.sql | mysql -h 127.0.0.1 -u USER -p beta_deschide

   SAU fără progress:
   mysql -h 127.0.0.1 -u USER -p beta_deschide < /home/radu/beta_backup.sql

3. Verifică:
   mysql -h 127.0.0.1 -u USER -p -e "USE beta_deschide; SHOW TABLES;"

---

## Note:

- Pentru MySQL local, HOST este probabil: 127.0.0.1 sau localhost
- USER ar putea fi: root, deschide_user, sau altul
- După ce completezi credentials, rulează comenzile de mai sus
