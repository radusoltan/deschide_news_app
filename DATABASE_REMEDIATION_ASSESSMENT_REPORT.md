   ```sql
   -- Check table growth rate

       count(DISTINCT article_id) as articles_tracked,

       count(*) as views,
       count(DISTINCT pv.visitor_id) as unique_visitors

   WHERE pv.viewed_at > now() - interval '7 days'
   GROUP BY a.id, a.title
   ORDER BY views DESC
   ```

### Priority 0 (CRITICAL - Implement Immediately)

#### 1. Configure Automated PostgreSQL Backups

**Recommended Strategy: pg_dump + Logical Backups**

Given the small database size (18 MB, max 2 GB), logical backups are appropriate and easier to manage than WAL archiving.

**Implementation:**

```bash
#!/bin/bash
# /usr/local/bin/backup_deschide_db.sh

set -e

BACKUP_DIR="/var/backups/postgresql/deschide"
DATE=$(date +%Y%m%d_%H%M%S)
RETENTION_DAYS=30

# Create backup directory
mkdir -p $BACKUP_DIR

# Backup database (compressed format)
PGPASSWORD='iIzmHACi7+W+yq9NFRT2FeadUPAmgEna' pg_dump \
    -h 127.0.0.1 \
    -U deschide_admin \
    -d deschide \
    -Fc \
    -f "${BACKUP_DIR}/deschide_${DATE}.dump"

# Backup to SQL format (human-readable, for quick restore)
PGPASSWORD='iIzmHACi7+W+yq9NFRT2FeadUPAmgEna' pg_dump \
    -h 127.0.0.1 \
    -U deschide_admin \
    -d deschide \
    --format=plain \
    | gzip > "${BACKUP_DIR}/deschide_${DATE}.sql.gz"

# Delete backups older than retention period
find $BACKUP_DIR -name "deschide_*.dump" -mtime +$RETENTION_DAYS -delete
find $BACKUP_DIR -name "deschide_*.sql.gz" -mtime +$RETENTION_DAYS -delete

# Log backup completion
echo "$(date): Backup completed - ${DATE}" >> /var/log/deschide_backup.log
```

**Cron Configuration:**

```bash
# Daily backup at 2 AM
0 2 * * * /usr/local/bin/backup_deschide_db.sh

# Weekly full backup on Sunday at 3 AM (kept for 90 days)
0 3 * * 0 /usr/local/bin/backup_deschide_db_weekly.sh
```

**Estimated Backup Times:**
- Current size (18 MB): < 5 seconds
- Production size (2 GB): < 2 minutes

#### 4. Implement Backup Monitoring and Alerting

**Create monitoring script:**

```bash
#!/bin/bash
# /usr/local/bin/check_backup_status.sh

BACKUP_DIR="/var/backups/postgresql/deschide"
MAX_AGE_HOURS=25  # Daily backup should be less than 25 hours old

LATEST_BACKUP=$(ls -t $BACKUP_DIR/*.dump 2>/dev/null | head -1)

if [ -z "$LATEST_BACKUP" ]; then
    echo "CRITICAL: No backups found in $BACKUP_DIR"
    exit 2
fi

BACKUP_AGE=$(($(date +%s) - $(stat -c %Y "$LATEST_BACKUP")))
BACKUP_AGE_HOURS=$((BACKUP_AGE / 3600))

if [ $BACKUP_AGE_HOURS -gt $MAX_AGE_HOURS ]; then
    echo "WARNING: Latest backup is ${BACKUP_AGE_HOURS} hours old (threshold: ${MAX_AGE_HOURS}h)"
    exit 1
else
    echo "OK: Latest backup is ${BACKUP_AGE_HOURS} hours old"
    exit 0
fi
```

**Add to cron (run every 6 hours):**

```bash
0 */6 * * * /usr/local/bin/check_backup_status.sh || mail -s "Backup Status Alert" admin@deschide.md
```
