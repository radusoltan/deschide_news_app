# Favicon Files Required

This directory needs the following favicon and logo files to be created:

## Required Files:

1. **favicon.ico** (16x16, 32x32, 48x48 multi-resolution)
   - Standard browser favicon
   - Format: ICO (multi-resolution)

2. **favicon-16x16.png**
   - Small favicon for browser tabs
   - Size: 16x16 pixels
   - Format: PNG with transparency

3. **favicon-32x32.png**
   - Medium favicon for bookmarks
   - Size: 32x32 pixels
   - Format: PNG with transparency

4. **apple-touch-icon.png**
   - iOS home screen icon
   - Size: 180x180 pixels
   - Format: PNG (no transparency needed)

5. **logo.png**
   - Main logo for schema.org Organization
   - Size: 512x512 pixels
   - Format: PNG with transparency

6. **logo-192.png**
   - PWA icon (small)
   - Size: 192x192 pixels
   - Format: PNG with transparency

7. **logo-512.png**
   - PWA icon (large)
   - Size: 512x512 pixels
   - Format: PNG with transparency

8. **og-image.png**
   - Default Open Graph image (social sharing)
   - Size: 1200x630 pixels
   - Format: PNG or JPG

## Design Guidelines:

- Use brand color: #1d4ed8 (blue)
- Keep design simple and recognizable
- Ensure high contrast for small sizes
- Use transparency for icons (except apple-touch-icon)
- Test visibility on both light and dark backgrounds

## Tools for Creation:

- Online: https://realfavicongenerator.net/
- Online: https://www.favicon-generator.org/
- Design tools: Figma, Adobe Illustrator, Sketch
- Image editors: GIMP, Photoshop
