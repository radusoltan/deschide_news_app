# Planuri Sprint

Planificarea și tracking-ul sprint-urilor de dezvoltare.

## Structură Sprint-uri

Fiecare sprint va avea propriul său document care include:
- Obiective sprint
- User stories și tasks
- Estimări (story points sau ore)
- Definition of Done
- Rezultate și retrospectivă

## Sprint-uri Planificate

### Sprint 0 - Setup & Infrastructure
- `sprint-0-setup.md` - Setup proiect, configurare infrastructure

### Sprint 1 - Core Entities & API
- `sprint-1-core-entities.md` - Entități de bază și API-uri publice

### Sprint 2 - Multilanguage & Images
- `sprint-2-multilanguage-images.md` - Sistem multilingv și procesare imagini

### Sprint 3 - Frontend Foundation
- `sprint-3-frontend-foundation.md` - Setup Next.js și componente de bază

### Sprint 4 - Integration & Polish
- `sprint-4-integration.md` - Integrare frontend-backend și refinement

## Template Sprint

Folosește `sprint-template.md` ca bază pentru fiecare sprint nou.
